# Security Policy

## Supported Versions

Octo Teacher is currently pre-1.0. Security fixes are applied to the latest `main` branch. Older builds and protocol generations may require re-binding rather than in-place migration.

## Reporting a Vulnerability

Use GitHub private vulnerability reporting for security and privacy issues. Do not open a public issue for vulnerabilities or include real family data in a report.

Include only the minimum information needed to reproduce the problem:

- Affected component and commit.
- Expected and observed behavior.
- A synthetic reproduction or redacted proof.
- Potential impact on authorization, family boundaries, Screen Time enforcement, or child privacy.

Never send live credentials, Apple signing keys, device tokens, database contents, family exports, child media, or private conversations. Revoke any credential that may have been exposed before submitting the report.

This project is maintained on a best-effort basis. You should receive an acknowledgement within seven days, followed by a remediation plan or a request for more information when possible.
